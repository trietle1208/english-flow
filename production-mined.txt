# Build Phase 1 — Personal English Learning Platform

## 1. Project Overview

Build a modern personal English learning web application.

This is NOT a student project or a demo-only application.

The goal is to build a real product that I will personally use for long-term English learning.

The application should be:

* Production-minded
* Maintainable
* Modular
* Responsive
* Fast
* Simple to operate
* Easy to extend in future phases
* Self-hostable
* Designed with data ownership in mind

Phase 1 should focus on the core learning experience.

Future phases may add:

* AI Tutor
* AI Conversation
* AI Grammar Correction
* Speaking evaluation
* Spaced Repetition
* Personalized learning recommendations

Do NOT implement those advanced AI features in Phase 1, but design the architecture so they can be added later without major rewrites.

---

# 2. Technology Stack

Use ONLY free/open-source technologies for the application.

## Frontend

* Next.js
* TypeScript
* App Router
* React
* Tailwind CSS
* shadcn/ui
* Lucide Icons

## Backend

Use Next.js as the application backend.

Use:

* Server Components where appropriate
* Server Actions where appropriate
* Route Handlers for APIs when needed

Do NOT create a separate Express or NestJS backend for Phase 1.

## Database

* PostgreSQL
* Drizzle ORM
* Drizzle Kit for migrations

The application must work with a PostgreSQL database running locally through Docker.

## Development Environment

Use:

* Docker
* Docker Compose

The goal is to allow the entire development environment to be started easily.

At minimum:

* Next.js application
* PostgreSQL database

should be supported through Docker Compose.

## Version Control

* Git
* GitHub

## Deployment

Keep the project compatible with:

* Vercel
* Any standard Node.js hosting
* Self-hosted Docker deployment

Do not introduce vendor-specific architecture that makes self-hosting difficult.

```text

```

Relationships:

```text
User
 ├── UserVocabulary
 ├── UserProgress
 ├── QuizAttempt
 └── PlacementTestAttempt

Course
 └── Lesson

Lesson
 ├── Vocabulary
 ├── GrammarTopic
 ├── ListeningLesson
 └── Quiz

Vocabulary
 └── UserVocabulary
```

Use foreign keys and indexes appropriately.

Use timestamps consistently.

Use UUIDs or another robust ID strategy.

Do not over-normalize data that does not need to be normalized.

# 42. Final UX Goal

The final application should feel like a real personal English learning system.

The core loop should be:

```text
Dashboard
    ↓
Continue Lesson
    ↓
Learn
    ↓
Save useful vocabulary ⭐
    ↓
Complete Exercise
    ↓
Complete Quiz
    ↓
Progress Updated
    ↓
Vocabulary appears in My Vocabulary
    ↓
Return to Dashboard
    ↓
Continue Learning
```

The application should make it extremely easy for the user to answer:

1. What should I learn today?
2. What am I currently learning?
3. Which words have I saved?
4. What have I already learned?
5. Where am I weak?
6. What should I do next?

Build Phase 1 around these questions.

Do not add unnecessary features that distract from this learning loop.
